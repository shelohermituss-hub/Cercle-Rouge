# Kit de marque Cercle Rouge

Fourni par le porteur le 2026-11-19. La source de vérité est la charte :
`Cercle-Rouge-Charte-Graphique-Identite-Visuelle.pdf`.

## Ce que l'app applique

| Élément | Charte | Dans l'app |
|---|---|---|
| Emblème | grille 100 × 100 : arc protecteur r 39, trait 8,5, `#A01515` ; arc de veille r 25,5, trait 7,5, `#E01E1E` ; noyau r 10,5, `#E01E1E` ; ouverture à droite | `LogoMark` (Compose), dessiné, jamais tourné |
| Logotype | « Cercle » Inter Medium noir (blanc en sombre), « Rouge » Inter Bold `#E01E1E` | `Wordmark` : proportions mesurées sur `Logo_Cercle Rouge.png` (corps du texte à 70 % de l'emblème) |
| Apparition | `cercle-rouge-motion-reveal.svg` : noyau, arc de veille, arc protecteur, puis les deux mots ; courbe (0,16, 1, 0,3, 1) | Démarrage (`Splash`), joué une fois, logo complet si les animations sont réduites |
| Icône Android | adaptative : emblème blanc sur Rouge Signal `#E01E1E`, zone sûre 66 % | `ic_launcher_*` (vecteurs) + icône thématique monochrome |
| Notification | emblème seul | `ic_notification` (aucun mot « alerte », R-SEC-06) |
| Rouges de l'interface | Grenat `#A01515` (SOS), Signal `#E01E1E` (alerte active) | dégradé Signal → Grenat du bouton SOS et des boutons de danger |

Les autres teintes (fond, encre, bleu d'action) restent celles du système « Verre » (`../systeme-verre.md`).

Usages proscrits (charte, § 5) : inverser les deux rouges, fermer les arcs, descendre sous 16 px, écrire le logotype
d'une seule graisse, ajouter ombres ou néon. L'ancien logo « en relief » du démarrage a été retiré pour cette raison.

Pour Google Play : `Logo_Cercle Rouge_Store principale.png` (fond Grenat) à exporter en 512 × 512.
